Documentation & Exemples

OpenClaw est un agent autonome qui s'installe sur votre machine. Il a accès à vos fichiers, votre terminal et Internet. Voici comment l'utiliser concrètement.

Installation rapide (Docker) docker run -d --name openclaw \ -v $(pwd)/workspace:/data/.openclaw/workspace \ -p 18789:18789 \ ghcr.io/openclaw/openclaw:latest

1. Le Développeur Fullstack

Génération & Déploiement

Ne perdez plus de temps sur le boilerplate. OpenClaw peut initialiser des projets, installer des dépendances et corriger des erreurs de build.

  • Création de projets (React, Vue, Node, Python)
  • Lecture et écriture de fichiers en temps réel
  • Exécution de commandes git (init, commit, push)
  • Débuggage automatique des erreurs de compilation
user@dev:~$ openclaw "Crée une API Express simple avec un endpoint /status et déploie sur Heroku"
Planification : 1. Créer dossier 2. Init npm 3. Code server.js 4. Git push...
⚡ Exécution des tâches...
> mkdir my-api && cd my-api
> npm init -y && npm install express
> Writing server.js... (Done)
📝 Contenu de server.js :
const express = require('express'); const app = express(); app.get('/status', (req, res) => res.json({status: 'OK'})); app.listen(process.env.PORT || 3000);
> git init && git add . && git commit -m "Init"
> heroku create && git push heroku main
✅ API déployée avec succès : https://stormy-waters-1234.herokuapp.com

2. L'Administrateur Système

user@server:~$ openclaw "Le site répond en 502 Bad Gateway. Analyse les logs et répare."
🔍 Investigation en cours...
> systemctl status nginx
● nginx.service - A high performance web server Active: active (running)
Nginx tourne. Vérifions les logs d'erreur.
> tail -n 20 /var/log/nginx/error.log
2026/02/24 [error] 123#123: *451 connect() failed (111: Connection refused) while connecting to upstream...
Erreur "Connection refused" vers l'upstream. Le backend Node.js est probablement crashé.
> pm2 status
│ app │ 0 │ stopped │ 0% │ 0b │
⚠️ DIAGNOSTIC : Le processus PM2 'app' est arrêté.
Action : Relance du service.
> pm2 restart app
✅ Service redémarré. Le site devrait être accessible.

Maintenance & Réparation

OpenClaw agit comme un opérateur niveau 1. Il connaît les commandes Linux standard et sait enchaîner les diagnostics logiques.

  • Lecture de logs (Nginx, Apache, Syslog)
  • Gestion de processus (Kill, Restart, PM2, Systemd)
  • Vérification des ressources (Disk space, RAM, CPU)
  • Il demande toujours confirmation pour les actions destructives

3. Le Chercheur Automatisé

Veille & Synthèse Web

OpenClaw est connecté au web. Il peut effectuer des recherches complexes, lire plusieurs pages et synthétiser l'information dans un fichier Markdown local.

  • Recherche multi-sources (Google, Docs officielles)
  • Extraction de données (Tableaux, Prix, Versions)
  • Rédaction de rapports au format Markdown
  • Traduction et résumé de contenus techniques
user@laptop:~$ openclaw "Trouve les 3 meilleures librairies Python pour le scraping en 2026 et fais un tableau comparatif dans README.md"
🌐 Recherche "best python scraping libraries 2026"...
Consultation de 4 résultats... Analyse des features...
📝 Rédaction du fichier README.md...
> cat README.md
# Comparatif Scraping Python 2026 | Librairie | Type | JS Support | Note | |-----------|------|------------|------| | **Crawl4AI** | AI-First | Oui (Chromium) | ⭐⭐⭐⭐⭐ | | **Scrapy** | Framework | Non (via plugin) | ⭐⭐⭐⭐ | | **BeautifulSoup** | Parser | Non | ⭐⭐⭐ | **Recommandation :** Utilisez Crawl4AI pour les sites modernes (SPA) et Scrapy pour le scraping de masse.
