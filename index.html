🛠️ SysAdmin & DevOps

"Pourquoi mon serveur est lent ?"
Vérifie CPU, RAM (top, htop) et identifie les coupables.
"Liste tous les conteneurs Docker qui tournent"
Exécute `docker ps` et formate la sortie.
"Nettoie les images Docker inutilisées"
Lance `docker system prune` pour libérer de l'espace.
"Analyse les logs Nginx pour trouver des erreurs 500"
Grep sur /var/log/nginx/error.log et résume.
"Crée un Cron pour sauvegarder ce dossier tous les soirs"
Écrit la ligne crontab correcte.
"Quels ports sont ouverts sur ma machine ?"
Utilise `netstat` ou `lsof` pour l'audit sécurité.
"Génère un certificat SSL auto-signé"
Utilise openssl pour créer les fichiers .key et .crt.
"Vérifie l'espace disque disponible"
Affiche un résumé clair de `df -h`.
